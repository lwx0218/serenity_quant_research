这一页是研究界面的全部视觉与文案规则。它很短,是故意的:规则少而硬,比长规格更容易被人和模型遵守。
方向稿:Claude Design 画布「CPO Explorer 视觉方向」(2026-09-02);实现:`web/`。

## 1. 一句话

**页面就是背景,部件就是产品。** 没有容器,没有面板,没有卡片;层级只靠留白、字号和三档灰度建立。一屏一个主角,一屏不超过一段说明。

## 2. 结构模型

Explorer 是**同一种视图的递归**,不是一组页面:

```text
容器(机柜 / 交换机 / 光模块) → 部件层(九层) → 子部件 → …
```

每一级都是「一个容器 + 它的部件列表」。位置永远只由顶部面包屑表达(`CPO 光模块 › 硅光芯片 › 光调制器`),不做侧边树、不做标签页。
选中一层不是「弹出信息卡」,而是「这一层成为新的主角」:其余层退成 `--dim`,内容直接铺在页面上,一条 L 形引线把对象和标题连起来。`Esc` 或点击空白回到整机。

## 3. 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 正文、标题、中文 | `Geist`(拉丁与数字)→ 系统中文字体(苹方 / 微软雅黑) | 自托管 `web/public/fonts`,OFL;不下载 CJK 字体 |
| 编号、代码、ticker、eyebrow | `Geist Mono` | 只做小字标注,永远不是主字体 |

字号刻度(px):12 eyebrow · 13 small · 15 body · 17 lead/row · 34 h2 · 56 h1 · 68 display。
eyebrow 一律大写、字距 0.14em、`--muted` 色。

## 4. 颜色

浅色与深色各一套变量,同名;组件只引用变量,不写死色值。

| 变量 | 作用 |
|---|---|
| `--bg` | 页面背景。浅色是暖白,深色是近黑 |
| `--ink` / `--ink-2` / `--muted` / `--faint` | 四档文字灰度:标题 / 正文 / 标注 / 装饰 |
| `--hair` / `--hair-2` | 发丝线。列表分隔与引线只用它们 |
| `--accent` | 唯一强调色。只用于:链接、当前引线、选中态的 eyebrow、悬停高亮 |
| `--m-*` | 分层图材质(铝、PCB、裸片、硅光、金、基板、黑塑)。深色版单独调过,不是反色 |

不用渐变背景,不用彩色徽章,不用阴影卡片。分层图的投影是唯一允许的阴影。

## 5. 组件词汇(只有这几种)

- **eyebrow + 标题 + 一段说明**:每个区块的头。
- **hairline rows**:所有列表。网格列、上边一条 `--hair`、悬停时标题变 `--accent`。没有卡片列表。
- **leader line**:锚点小圆 + 1px 线,连接图与文字。
- **面包屑**:唯一的位置指示。
- **mono 小标注**:编号、ticker、证据级。

需要新组件时,先问「能不能用上面五种拼出来」。

## 6. 文案

- 中文为主;英文只作 mono 小标注或专名。不做「英文 / 中文(括号解释)」三段式标签。
- 界面上不出现只有开发者才懂的词:轮次号、实现术语(projection、linked-object、CompanyExposure)、边界声明、免责段落。
- 证据级用三个词:**已核验 / 候选 · 待核验 / 行业图示**。来源信息放在公司页,整页只在页脚出现一次来源说明。
- 没有数据就不放这个模块,不放 `Unknown` 徽章。空态是一句话。

## 7. 禁区

- 卡片套卡片、每个 section 一个白底圆角框
- 顶部堆叠多层标题 / 说明 / 筛选器才见到内容
- 同一信息在一页内重复出现(如来源路径出现两次)
- 为了「完整」而加的 tab、filter、dashboard、badge
- 把 prototype 或图示里的数字(份额、BOM%、国产化率)当成事实展示

## 8. 布局与响应

当前为桌面优先:内容宽 1280,页边 80,Explorer 的图与标注使用固定坐标(见 `ExplorerPage.tsx` 的 `OVERVIEW` / `FOCUSED`)。
小于 1280 的视口尚未适配;移动端不在 v1 范围。
