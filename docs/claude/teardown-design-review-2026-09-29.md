## A. 结构层

**A1 · 公司池与公司页还站在旧分类上。** 公司池按 main 的产业链环节分组（需求侧 / 交换芯片 …），130 家只在实物层的公司显示「尚未关联环节 · —」；公司页的身份行（「硅光芯片 · 硅光芯片篮子 →」）、右栏「在整机中 / 被引用」、「待核验 · 行业图示 → 候选」、页底「在产业链中的位置」全是 main 的层与 exposures；实物位置「在实物里的位置」压在判断之后。东山精密一页上同时写「基板与互连 · 共封装基板篮子」（旧）和「整模块」（实物），互相矛盾。
做法：公司的身份 = 它站在哪几个部件上。公司池按部件（站）分组、证据级取实物层、加「有行情 / A 股」筛选；公司页顺序改为 头（站在 N 个部件上 · 主要部件）→ 结论 → 价格 → 拥挤度 → 卡口事件 → 共振 → 判断；「在实物里的位置」并进头部与右栏；「待核验」（exposures 升级流程）与「在产业链中的位置」退役——证据现在在实物映射里、带来源，事件自动入账后也不再需要「用公告升级一条关系」。

**A2 · 研究页还是层的世界。** 右栏 rail 是九个模块层，「篮子偏离」告警按层篮子，「待核验」按 exposures，「时效按各层事件效力」，头部一行「有行情 0 / 可取 144 / 真 · 示例 / 交给 AI 补」是运维词汇。
做法：rail 换成部件（九站在前，其余成篮子的部件在后）；偏离告警按部件篮子；「待核验」块由自动入账状态行取代（已做）；运维那一行收到页脚一句「行情截至 … · 事件 N 条」，其余进 `/api/ingest/status` 不上页面。

**A3 · 首页表 17 行里 9 行全是「—」。** 规则说没有数据就不放模块。做法：没篮子也没事件的部件折成一行「另 N 个部件没有能进篮子的上市公司 →」，点开再展开。

## B. 回答「够不够直接」的那个数：事件效力要到部件级

层篮子页（`/baskets/cpo.mod.pic`）有「事件效力」块（样本 N 条 · 平均反应 T+1/T+5/T+20 · 命中率 · 半衰期）——这正是判断「事件 → 市场」直接不直接的统计量，但它只按层算（`market.efficacy_for(node_id)`）。部件右栏没有它，部件结论句里「事件效力只有约 5 天」是常量 `DEFAULT_VALIDITY_DAYS`，不是统计（insights.basket 在 efficacy=None 时仍写出天数）。
做法见 `teardown-accounting-v2.md` §4：`efficacy_for_part`（窗口 365 天、每周重算、样本 < 5 写「样本不足」）；部件右栏「资金投票」之后加「事件效力 · 这个部件」四行；层篮子页整页改成部件篮子页 `/baskets/part.*`（效力 / 拥挤度 / 成分 / 其他部件，结构不变），层篮子只从 `/layers` 进；首页表加一列「命中率」（有样本才显示）。

## C. 结论句正确性（必修）

- `insights.overview`：`direction = pos if excess > 0 else neg` 没有阈值，同页呼吸点与表格行用 ±0.5%；篮子 +0.2% 时结论 ▲ 行内 ●；0.0 时写「资金在离开 X 0.0%」。改：`active` 只收 direction ∈ {pos, neg}，否则 neu。「没有一层的篮子给出方向」→ `f"没有一个{unit}的篮子…"`。反例只取 lead 部件自己的事件、方向与结论相反（d2c39cc 已做）。
- `insights.basket`：efficacy 为 None 时删去「时效约 N 天」分句。`company_events`：voted > 1 条时不再写「只有 … 那条」。

## D. 卫生项（按序）

1. 对比度：浅色 `--muted #8a8e96` 对 `--bg` 3.04:1，却承担面包屑、截至/窗口、eyebrow、时效、阈值说明；改 `#6a6e76`（4.73:1）。`--faint`（1.78:1）只做装饰，「未命中」、禁用按钮文字、走势图整机参照线改 `--muted`。方向色不落到序号（`.row-index.is-pos`）和错误提示上。
2. 选中态用 `opacity:0; pointer-events:none` 藏的九站按钮、投票行、TX/RX、「按产业链分层看」仍在 Tab 序列，Enter 会悄悄换选中或切 RX；SVG 隐形站号圆仍接住 hover。改 `visibility: hidden`（过渡 `visibility 0s linear .28s`）或 `inert`。
3. Esc 冒泡：判断块「+ 新问题」输入框按 Esc 会把整页视图关掉；输入框 `stopPropagation`，页面级监听跳过 input/textarea。
4. 防错：`/explore/xyz` 失败后 error 不清空；`?part=` 不存在时舞台空白 900px 无提示（replace 到不带 part 的路由）；`new URL(official_url)` 非法时白屏（try/catch）。
5. 加载态被当空态：`nm`/`detail` 未到先闪「还没有判断」「暂无公司」；审核 / 驳回 / 延期无 busy 与失败提示（照 Candidates 的模式）。
6. 键盘：图上的 `g[data-part]` 无 role/tabindex（无站点的部件只能鼠标点）；`EventsWide` 有 onPick 时仍是 div；LineChart `role="img"` 无 aria-label；面包屑末项 `aria-current`。
7. 命中区 < 24px：TX/RX、`.btn`、问题状态切换、证据级链接；`min-height:24px` + 负 margin 保排版；TX/RX 加 `aria-pressed`。
8. 引线穿字：`.ph-stations-head` 在 (0, 966)，第 1、2 列引线竖段 x = 12 / 156 正好穿过「信号怎么走 · 发送 · 九站」；眉题左移 24px 并缩短，或并入图例块。
9. 「窗口」槽位放了口径：层视图 / 公司页 / 收件箱写「窗口 T+1 相对篮子」，真正的窗口天数没出现；物理页已正确（窗口 30 天，口径在 extra），三处照它改。
10. 文案：层 / 环节 / 部件三个词统一（rail「层」、「相邻层」、「时效按各层事件效力」、resonance「层级事件…」）；「十个环节」写死改成数据长度；`"Private"` → 未上市；「覆盖层 = 全球锚点 / A 股重点 / 行业图示收录」删；「阈值可调」删；物理页面包屑首项与 hero 眉题都写 Quantum-X800（重复且不可点）。
11. `a { color }` 被 `.small` / `.row-meta` 压成灰：「看实物 →」「按产业链分层看 →」（/layers 唯一入口）不像链接；`.rows-end` 与 `.rows::after` 叠成 2px 底线；刻度 2.5 步长被四舍五入成 98/103。
